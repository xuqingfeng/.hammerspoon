### SelectSearch

Select some text (or copy a link) and press `⌥⌘S` to search, translate, or jump to it in the default browser.

Actions:
- `🔗 Go To Link` — open the text as a link when it contains a URL
- `🔍 Google Search` — search with Google
- `🌐 Google Translate` — translate with Google
- `📘 有道翻译` — translate with Youdao
- `📕 Wikipedia` — open the Wikipedia page
